## 1. 绪论

### 1.1 数据结构研究

数据结构是一门研究非数值计算的程序设计中计算机的操作对象以及它们之间的关系和操作的学科



### 1.2 基本概念和术语

#### 1.2.1 数据、数据元素、数据项和数据对象

- 数据

- 数据元素，一条条数据元素就是组成数据的基本单位
- 数据项，构成数据元素的不可分割的最小单位，例如数据元素的某一属性
- 数据对象，性质相同的数据元素的集合，是数据的一个子集

数据>>数据元素>>数据项



数据元素——组成数据的基本单位

数据对象——性质相同的数据元素的集合



数据结构——数据元素相互之间的关系称为结构

数据结构包含以下三个方面内容：

- 数据元素之间的逻辑结构
- 数据的物理结构或数据的存储结构
- 数据的运算与实现



#### 1.2.2 数据结构

**（1）逻辑结构**

**线性结构**

仅有一个开始和一个终端结点，并且所有结点最多只有一个直接前驱和一个直接后继

例如：线性表、栈、队列、串

**非线性结构**

一个结点可能有多个直接前驱和直接后继

例如：树、图

**（2）存储结构**

**顺序存储结构**

用一组连续的存储单元依次存储数据元素，数据元素之间的逻辑关系由元素的存储位置来表示

**链式存储结构**

用一组任意的存储单元存储数据元素，数据元素之间的逻辑关系用指针来表示

存储每一个元素本身同时存储下一个元素地址

**索引存储结构**

在存储结点信息的同时，还建立附加的索引表

**散列存储结构**

根据结点的关键字直接计算出该结点的存储地址

**（3）数据的运算**

检索、排序、插入、删除、修改等

- 约束变量或常量的操作

### 1.4 算法和算法分析

算法是解决问题的一种方法或一个过程，考虑如何将输入转换成输出，一个问题可以有多种算法

程序是用某种程序设计语言对算法的具体实现



算法必须具有五个重要特性：

- **有穷性**：一个算法必须总是在执行有穷步之后结束，且每一步都在有穷时间内完成。
- **确定性**：算法中的每一条指令必须有确切的含义，没有二义性，在任何条件下，只有唯一的一条执行路径，即对于相同的输入只能得到相同的输出。
- **可行性**：算法是可执行的，算法描述的操作可以通过已经实现的基本操作执行有限次来实现。
- **输入**：一个算法有零个或多个输入。
- **输出**：一个算法有一个或多个输出。

算法设计的要求

- 正确性
- 可读性
- 健壮性
- 高效性



**算法的效率**

算法效率以以下两个方面考虑

- **时间效率**：指算法所耗费的时间
- **空间效率**：指算法执行过程所耗费的存储空间



**渐进时间复杂度**

算法时间效率的度量

- 事后统计
- 事前分析
  - 用一个简单操作所需时间 × 简单操作次数

\[
算法运行时间 = \sum 每条语句的执行次数 × 该语句执行一次所需的时间
\]

**例1**

```C++
for(i=1;i<=n;i++)          // n+1 次
    for(j=1;j<=n;j++){     // n(n+1) 次
        c[i][j]=0;         // n² 次
        for(k=0;k<=n;k++)  // n²(n+1) 次
            c[i][j]=c[i][j]+a[i][k]*b[k][j]; // n³ 次
    }
```


\[
\begin{align*} 
 (T(n)) &= (n+1)+n(n+1)+n^2+n^2(n+1)+n^3 \\ 
 &= n+1 + n^2+n + n^2 + n^3+n^2 + n^3 \\ 
 &= \boldsymbol{2n^3 + 3n^2 + 2n + 1} 
 \end{align*}
\]
O(n)为衡量算法的时间复杂度，只保留最高阶项，忽略系数和低次项： \( (T(n))=O(n^3) \)



**例2**

```C++
for( i=1; i<=n; i++ )
    for (j=1; j<=i; j++ )
        for (k=1; k<=j; k++ )
            x = x + 1;
```

\[
\begin{align*} \text{频度} &= \sum_{i=1}^{n}\sum_{j=1}^{i}\sum_{k=1}^{j} 1 \\ 
&= \sum_{i=1}^{n}\sum_{j=1}^{i} j \\ &= \sum_{i=1}^{n} \frac{i(i+1)}{2} \\ &=\frac12\sum_{i=1}^n(i^2+i) =\frac{n(n+1)(n+2)}{6} 
\end{align*}
\]

\((T(n))=O(n^3)\)



**例3**

```C++
i = 1;
while(i <= n)
    i = i * 2;
```

设循环体 `i=i*2;` 一共执行 \(x\) 次：

- 初始：\(i=1=2^0\)
- 执行1次：\(i=2^1\)
- 执行2次：\(i=2^2\)
- 执行\(x\)次：\(i=2^x\)

循环条件：执行完之后仍然要满足\(2^x \le n\) ，\(2^x \le n\) 两边取以2为底的对数： \(x \le \log_2 n\) 循环最多执行 \(\boldsymbol{\log_2 n}\) 次，所以时间复杂度： \(\boldsymbol{T(n)=O(\log_2 n)}\)



算法中基本操作重复执行的次数还随问题的输入数据集不同而不同，考虑算法时间复杂度还要分别考虑以下：

- 最坏时间复杂度

- 平均时间复杂度

- 最好时间复杂度

一般考虑在最坏情况下的时间复杂度，以保证算法的运行时间不会比它更长



**渐进空间复杂度**

算法所需存储空间的度量

- 算法本身要占据的空间，输入输出，指令，常数，变量等
- 算法要使用的辅助空间

【算法1】原地逆置

```C++
for(i=0;i<n/2;i++) {
    t=a[i];
    a[i]=a[n-i-1];
    a[n-i-1]=t;
}
```

- 只用到一个临时变量 `t`，额外空间数量和 (n) 无关
- 空间复杂度：\(S(n)=O(1)\)
- 特点：**原地算法**，不新开数组

【算法2】借助辅助数组逆置

```C++
for(i=0;i<n;i++)
    b[i]=a[n-i-1];
for(i=0;i<n;i++)
    a[i]=b[i];
```

- 额外开辟了长度为 \(n\) 的数组 `b`
- 空间复杂度：\(S(n)=O(n)\)



## 2.线性表

### 2.1 线性表的定义和特点

线性表示具有相同特性的数据元素的一个有限序列
\[
(a_1, a_2, \dots, a_{i-1}, a_i, a_{i+1}, \dots, a_n)
\]

- \(a_1\) ：起始结点

- \(a_n\) ：终端结点
- \(a_{i-1}\)：\(a_{i}\) 的直接前驱
- \(a_{i+1}\)：\(a_{i}\) 的直接后继
- n 为表长，n=0代表空表



### 2.2 案例引入

- **一元多项式的运算**

\[
P_(x) = p_0 + p_1x + p_2x^2 + \dots + p_nx^n
\]

用线性表记作：
\[
P=(p_0,p_1,p_2,\dots,p_n)
\]

- 下标 i：对应项的指数
- \(p_i\)：\(x^i\) 这一项的系数



\(P(x) = 10 + 5x - 4x^2 + 3x^3 + 2x^4\)

| 指数（下标 i） | 0    | 1    | 2    | 3    | 4    |
| -------------- | ---- | ---- | ---- | ---- | ---- |
| 系数 \(p[i]\)  | 10   | 5    | -4   | 3    | 2    |

线性表：\(P=(10,\ 5,\ -4,\ 3,\ 2)\)
\[
R_n(x)=P_n(x)+Q_m(x)
\]
线性表 \(R = (p_0 + q_0,\ p_1 + q_1,\ p_2 + q_2,\dots,p_m + q_m,\ p_{m+1},\dots,p_n)\)

- **稀疏多项式的运算**

\[
S(x) = 1 + 3x^{10000} + 2x^{20000}
\]

会造成存储空间很大浪费

$$A(x) = 7 + 3x + 9x^8 + 5x^{17}$$

| 下标i     | 0    | 1    | 2    | 3    |
| --------- | ---- | ---- | ---- | ---- |
| 系数 a[i] | 7    | 3    | 9    | 5    |
| 指数      | 0    | 1    | 8    | 17   |

> 稀疏多项式存储：同时保存**系数**和**指数**，只存非0项。

\[
P_n(x)=p_1x^{e_1}+p_2x^{e_2}+\dots+p_mx^{e_m}
\]

线性表 \(P=((p_1,e_1),(p_2,e_2),\dots,(p_m,e_m))\)

### 2.3 线性的类型定义

抽象数据类型线性表定义如下

```C++

	数据对象
    数据关系
	基本操作
    InitList(&L);
    DestroyList(&L);
    ListInsert(&L, i, e);
    ListDelete(&L, i, &e);
    ...
}ADT List
```



- **线性表的初始化** InitList(&L)
  - 构造一个空的线性表
- **线性表的销毁** DestoryList(&L)
  - 线性表已存在，销毁线性表
- **线性表的清除** ClearList(&L)
  - 线性表已存在，将线性表重置为空表
- **判断线性表是否为空** ListEmpty(L)
  - 线性表已存在，若为空返回True，否则返回False
- **线性表有几个元素** ListLength(L)
  - 线性表已存在，返回线性表中数据元素个数
- **获取线性表中元素** GetElem(L, i, &e)
  - 线性表已存在，且1<=i<=ListLength(L)，用e返回线性表L中第i个数据元素的值
- **线性表元素判定** LocateElem(L, e, compare())
  - 返回L中第1个与e满足compare()的数据元素的位序，若不存在则返回0
- **获取一个元素前驱** PriorElem(L, cur_e, &pre_e)
  - 线性表L已存在，若cur_e是L数据元素，且不是第一个，用pre_e返回它的前驱，否则失败
- **获取一个元素后继** NextElem(L, cur_e, &next_e)
  - 线性表L已存在，cur_e是L的数据元素，且不失最后一个，则用next_e返回它的后继，否则失败
- **线性表中插入元素** ListInsert(&L, i, e)
  - 线性表已存在，1<=i<=ListLength(L)+1，在L的第i个位置之前插入新的数据元素e，L的长度+1
- **线性表中删除元素** ListDelete(&L, i, &e)
  - 线性表已存在，1<=i<=ListLength(L)，删除L中第i个数据元素，并用e返回其值，L的长度-1
- **线性表遍历** ListTraverse(&L, visited())
  - 线性表已存在，依次对线性表中每个元素调用visited()

**顺序表的查找**

- 在线性表L中查找与指定值e相同的数据元素的位置




#### 顺序表查找算法分析（平均查找长度 ASL）

**1. 平均查找长度（ASL）通用公式**

为了衡量查找算法的时间性能，通常计算查找成功时的**平均查找长度**（Average Search Length, $ASL$）：   
\[
ASL = \sum_{i=1}^{n} P_i C_i
\]

- \(n\)：表中记录的元素总个数。   
- \(P_i\)：第 \(i\) 个记录被查找的概率。   
- \(C_i\)：找到第 \(i\) 个记录所需的关键字比较次数。   

**2. 顺序查找的比较次数展开**

在顺序查找中，从表头向后逐个比对：

- 找第 1 个元素需比较 1 次；   
- 找第 2 个元素需比较 2 次；   
- 找第 \(i\) 个元素需比较 \(i\) 次（即 \(C_i = i\)）；   
- 找第 \(n\) 个元素需比较 \(n\) 次。   

将各单项展开，得到顺序查找的 $ASL$ 计算式：
\[
ASL = P_1 + 2P_2 + \dots + (n-1)P_{n-1} + nP_n
\]
**3. 等概率情况下的推导过程**

假设每个记录被查找的概率相等（即等概率分布）：
\[
P_1 = P_2 = \dots = P_n = \frac{1}{n}
\]
代入通用公式进行推导：
\[
ASL_{ss} = \sum_{i=1}^{n} P_i C_i = \frac{1}{n} \sum_{i=1}^{n} i = \frac{1}{n} (1 + 2 + \dots + n)
\]




利用等差数列求和公式 $\sum_{i=1}^{n} i = \frac{n(n + 1)}{2}$，进一步化简：
\[
ASL_{ss} = \frac{1}{n} \cdot \frac{n(n + 1)}{2} = \frac{n + 1}{2}
\]


**顺序表的插入**

- 插入位置是否合法
- 判断顺序表存储空间是否已满
- 将第n至第i位元素依次向后移动一个位置，空出第i个位置
- 将要插入的新元素e放入第i个位置，表头+1

```C++
Status ListInsert_Sq(SqList &L, int i, ElemType e)
{
    if(i < 1 || i > L.length+1)
        return ERROR;
    if(L.length == MAXSIZE)
		return ERROR;
    for(int j=L.length-1; j >= i-1; --j)
        L.elem[j+1] = L.elem[j];
    L.elem[i-1] = e;
    ++L.length;
}
```

移动次数和插入位置的和为 n+1



- **基本规律**：插入第 \(i\) 个位置时，原表前 \(i - 1\) 个元素不动，从第 \(i\) 个到第 \(n\) 个元素均需后移。   

- **单次移动次数**：
  \[
  x = n - i + 1
  \]
  
  
  

  - 即：\(\text{插入位置 } i + \text{移动次数 } x = n + 1\)。

- **极值情况**：

  - **最好情况**：插入在表尾（\(i = n + 1\)），移动 0 次，时间复杂度为 \(O(1)\)  
  - **最坏情况**：插入在表头（\(i = 1\)），移动 n 次，时间复杂度为 \(O(n)\)

####  平均移动次数（\(E_{ins}\)）推导

假设在 \(n + 1\) 个合法位置（\(1 \le i \le n + 1\)）插入的概率均等（\(P_i = \frac{1}{n + 1}\)）：   
\[
E_{ins} = \sum_{i=1}^{n+1} P_i (n - i + 1) = \frac{1}{n + 1} \sum_{i=1}^{n+1} (n - i + 1)
\]


展开求和并代入等差数列公式：   
\[
E_{ins} = \frac{1}{n + 1} (n + \dots + 1 + 0) = \frac{1}{n + 1} \cdot \frac{n(n + 1)}{2} = \frac{n}{2}
\]


#### 核心结论

- **平均移动次数**：\(\frac{n}{2}\)（平均需搬移表中一半的元素）
- **平均时间复杂度**：\(O(n)\)



**顺序表的删除**

- 判断删除位置i是否合法
- 将欲删除的元素保留在e中（可省略）
- 将第i+1至第n位的元素依次向前移动一个位置
- 表长-1，删除成功返回OK

```C++
Status ListDelete_Sq(SqList &L, int i)
{
    if ((i<1)||(i>L.length))
        return ERROR;
    for(int j=1;j<=L.length-1;++j)
        L.elem[j-1] = L.elem[j];
    L.length--;
    return OK;
}
```



**单次移动次数**：
\[
x = n - i
\]
假设在 \(n\) 个合法位置（\(1 \le i \le n\)）插入的概率均等（\(P_i = \frac{1}{n}\)）：
\[
E_{del} = \frac{1}{n}\sum_{i=1}^n(n-i)=\frac{1}{n}\frac{n(n-1)}{2} = \frac{n-1}{2}
\]




### 2.5 线性表和链表的比较

**顺序表的特点**：以物理位置相邻表示逻辑关系

**顺序表的优点**：任一元素均可随机存取

**顺序表的缺点**：进行插入和删除操作时，需移动大量的元素，存储空间不灵活



**链式存储结构**：节点在存储器中的位置是任意的，即逻辑上相邻的数据元素在物理上不一定相邻

线性表的链式表示又称为非顺序映像或链式映像



1. 结点：数据元素的存储映像，由数据域和指针域两部分组成
2. 链表：n个结点由指针链组成一个链表，它是线性表的链式存储映像，称为线性表的链式存储结构



**单链表**：结点只有一个指针域的链表，称为单链表或者线性链表

**双链表**：结点有两个指针域的链表，称为双链表

**循环链表**：首尾相接的链表称为循环链表



| head→  | info→  | a1→      | a2→  | ...  | an ^d |
| ------ | ------ | -------- | ---- | ---- | ----- |
| 头指针 | 头结点 | 首元结点 |      |      |       |

头指针：指向链表中第一个结点的指针

首元结点：指链表中存储第一个数据元素 \(a_1\) 的结点

头结点：链表的首元结点之前附设的一个结点



无头结点时，头指针为空时表示空表 `head ^`

有头结点时，当头结点的指针域为空时表示空表 `info ^`



头结点的优点：

- 便于首元结点的处理
- 便于空表和非空表的统一处理

**链表的特点**

- 结点在存储器的位置是任意的

- 访问时只能通过头指针进入链表，并通过每个结点的指针域依次向后顺序扫描其余结点，所以第一个结点和最后一个节点所花时间不等

#### 单链表取值（取单链表中第i个元素的内容）

从链表的头指针出发，沿着链域next逐个结点往下搜索，直至搜索到第i个结点为止或后面没有元素了

【算法步骤】

- 从第1个结点（L->next）顺链扫描，用指针p指向当前扫描到的结点，p初值p=L->next
- j做计数器，累计当前扫描过的结点数，j初值为1
- 当p指向扫描到的下一结点时，计数器j加1
- 当j==i时，p所指的结点就是要找的第i个结点

```C++
Status GetElem_L(LinkList L, int i, ElemType &e)
{
    p = L->next; j = 1; // 初始化
    while(p&&j<i) 		// 向后扫描，直到p指向第i个元素或p为空
    {
        p=p->next; ++j;
    }
    if(!p || j > i)
        return ERROR; // 第i个元素不存在
    e = p->data;      // 取第i个元素
    return OK;
}
```



#### 单链表的按值查找

**根据指定数据获取该数据所在的位置（地址）**

【算法步骤】

- 从第一个结点起，依次和e相比较
- 如果找到一个值与e相等的数据元素，则返回其在链表中的位置或地址
- 如果查遍整个链表都没有找到其值和e相等的元素，则返回0或NULL

```C++
Lnode *LocateElem_L(LinkList L, Elemtype e)
{
    // 在线性表L中查找值为e的数据元素
    // 找到则返回L中值为e的数据元素的地址，查找失败返回NULL
    p = L->next;
    while(p&&p->data!=e)
        p = p->next;
    return p;
}
```



**根据指定数据获取该数据位置序号**

```C++
// 在线性表L中查找值为e的数据元素的位置序号
int LocateElem_L(LinkList L, Elemtype e)
{
```

#### 单链表插入

**在第i个结点前插入值为e的新结点**

【算法步骤】

- 首先找到 \(a_{i-1}\) 的存储位置 p
- 生成一个数据域为 e 的新结点 s
- 插入新结点，①新结点的指针域指向结点 \(a_i\)，②结点 \(a_{i-1}\) 的指针域指向新结点
- `①s->next = p->next;②p->next=s;`

```C++
// 在L中第i个元素之前插入数据元素e
Status ListInsert_L(LinkList &L, int i, ElemType e)
{
    p=L; j=0;
	while(p && j<i-1)
    {
        p=p->next;
        ++j; // 寻找第i-1个结点，p指向i-1结点
    }
    if(!p || j > i-1) // i大于表长+1或小于1 插入位置非法
        return ERROR;
    s = new LNode; 	   // 生成新结点s，并将结点的数据域置为e
    s->data = e;
    s->next = p->next; // 将结点s插入L中
    p->next = s;
    return OK;
}
```



#### 单链表删除

【算法步骤】

- 首先找到 \(a_{i-1}\) 的存储位置 p，保存要删除的 \(a_i\) 的值
- 令 p->next 指向 \(a_{i+1}\)

- \(a_{i-1}\)→\(a_{i+1}\)：(p->next)->next

- 则删除 \(a_i\) 就是让\(a_{i-1}\)的地址连接\(a_{i+1}\)，即 p->next = p->next->next;

```C++
// 将线性表L中第i个数据元素删除
Status ListDelete_L(LinkList &L, int i, ElemType &e)
{
    p=L, j=0;
    while(p->next && j<i-1) // 寻找第i个结点，并令p指向其前驱
    {
        p = p->next;
        ++j;
    }
    if(!(p->next) || j>i-1) // 删除位置不合理
        return ERROR;
    q = p->next; // 临时保存被删除结点的地址以备释放
    p->next=q->next; // 改变删除结点前驱结点的指针域
    e = q->data; // 保存删除结点的数据域
    delete q; // 释放删除结点的空间
    return OK;
}
```



#### 单链表的查找、插入、删除算法时间效率

**1.查找**：O(n)

**2.插入和删除**：只要修改指针，一般时间复杂度为O(1)，但若要进行前插或者删除，由于要从头查找前驱结点，时间复杂度为O(n)



#### 单链表的建立

**头插法**：元素插入在链表头部，也叫前插法

【算法步骤】

- 1.从一个空表开始，重复读入数据
- 2.生成新结点，将读入数据存放到新结点的数据域中
- 3.从最后一个结点开始，依次将各结点插入到链表的前端

```C++
void CreateList_H(LinkList &L, int n)
{
    L = new LNode;
    L->next=NULL;
    for(int i = n; i>0; --i)
    {
        p = new LNode;
        cin >> p->data;
        p ->next=L->next;
        L->next=p;
    }
}
```

时间复杂度O(n)



**尾插法**：元素插在链表的尾部

【算法步骤】

- 1.从一个空表L开始，将新结点逐个插入到链表的尾部，尾指针r指向链表的尾结点
- 2.初始时，r同L均指向头结点，每读入一个数据元素则申请一个新结点，将新结点插入到尾结点后，r指向新结点

```C++
void CreateList_R(LinkList &L, int n)
{
    L = new LNode;
    L->next=NULL;
    r=L; // 尾指针r指向头结点
    for(int i=0; i<n; ++i)
    {
        p = new LNode;	// 生成新结点
        cin >> p->data; // 输入元素值
        p->next = NULL; // 新结点是新的尾巴置空
        r->next=p;		// 新结点挂到当前尾结点后面 
        r=p; // r指向新的尾结点
    }
}
```

时间复杂度O(n)



### 2.5.3 循环链表

循环链表：一种头尾相接的链表

优点：从表中任一结点出发均可找到表中其他结点



循环链表中头结点的指针域连接自身，也因为循环链表没有NULL指针，所以遍历终止时，判断它们是否是头指针终止



循环条件

`p!=NULL` → `p!=L`

`p->next!=NULL`→`p->next!=L`



同时，使用尾指针既方便查看an，又可以通过`R->next-next`指向首元结点，所以使用尾指针



#### 带尾指针循环链表Ta、Tb合并

- p存表头结点 `p=Ta->next;`

- Tb表头连接Ta表尾 `Ta->next = Tb->next->next;`
- 释放Tb表头结点 `delete Tb->next;`
- 修改指针 `Tb->next=p;`



```C ++
LinkList Connect(LinkList Ta, LinkList Tb)
{
    // 假设Ta、Tb都是非空的单循环链表
    p = Ta->next; 			 // ① p存表头结点 
    Ta->next=Tb->next->next; // ② Tb表头（首元结点）连结Ta表尾
    delete Tb->next;		 // ③ 释放Tb表头结点
    Tb->next=p;				 // ④ 修改指针
    return Tb;
}
```



#### 2.5.4 双向链表

单链表的结点找后继结点方便，执行时间为O(1)，查前驱节点的执行时间为O(n)

双向链表：在单链表的每个结点里再增加一个指向其直接前驱的指针域prior，这样就构成了双向链表

双向链表的结构可定义如下

```C++
typedef struct DuLNode
{
    Elemtype data;
    struct DuLNode *prior, *next;
}DuLNode, *DuLinkList;
```

双向循环链表

- 让头结点的前驱指针指向链表的最后一个结点
- 让最后一个结点的后继指针指向头结点

双向链表结构的对称性`p->prior->next = p = p->next->prior`



#### 双向链表的插入

`... ↔ [a] ↔ [b] ↔ ...`→`... ↔ [a] ↔ [x] ↔ [b] ↔ ...`

- `s->prior=p->prior;`原本由b指向a的前驱指针变成由x指向a的前驱指针
- `p->prior->next=s;`原本a的后继为b现在改为x
- `s->next=p;`x的后继改为b
- `p->prior=s;`

```C++
void ListInsert_DuL(DuLinkList &L, int i, ElemType e)
{
    if(!(p=GetElemP_DuL(L, i))) // 位置不合理得到空指针返回错误
        return ERROR;
    s = new DuLNode;
    s->data = e;
    s->prior = p->prior;
    p->prior -> next = s;
    s->next = p;
    p->prior = s;
    return OK;
}
```



#### 双向链表的删除

- p->prior->next=p->next;

- p->next->prior=p->prior;

```C++
void ListDelete_DuL(DuLink &L, int i, ElemType &e)
{
    if(!(p=GetELemP_DuL(L, i)))
        return ERROR;
    e = p->data;
    p->prior->next=p->next;
    p->next->prior=p->prior;
    free(p);
    return OK;
}
```



#### 单链表、循环链表、双向链表的时间效率比较

| 链表类型                          | 查找表头结点（首元结点） | 查找表尾结点                          | 查找结点 *P 的前驱结点                    |
| --------------------------------- | ------------------------ | ------------------------------------- | ----------------------------------------- |
| 带头结点的单链表 L                | L->next时间复杂度O(1)    | 从 L->next 依次向后遍历时间复杂度O(n) | 通过 p->next 无法找到其前驱               |
| 带头结点仅设头指针 L 的循环单链表 | L->next时间复杂度O(1)    | 从 L->next 依次向后遍历时间复杂度O(n) | 通过 p->next 可以找到其前驱时间复杂度O(n) |
| 带头结点仅设尾指针 R 的循环单链表 | R->next时间复杂度O(1)    | R时间复杂度O(1)                       | 通过 p->next 可以找到其前驱时间复杂度O(n) |
| 带头结点的双向循环链表 L          | L->next时间复杂度O(1)    | L->prior时间复杂度O(1)                | p->prior时间复杂度O(1)                    |



### 2.6 顺序表和链表的比较

**链式存储结构优点**：

- 节点空间可以动态申请和释放

- 护具元素的逻辑次序靠结点的指针来指示，**插入和删除时不需要移动数据元素**

**链式存储结构的缺点**：

- 存储密度小，每个节点都指针域需要额外占用存储空间，当每个结点的数据域所占字节不多时，指针域所占存储空间的比重显得很大

\[
存储密度 = \frac{节点数据本身占用的空间}{节点占用的空间总量}
\]

| 比较项目     |            | 顺序表                                                       | 链表                                                 |
| ------------ | ---------- | ------------------------------------------------------------ | ---------------------------------------------------- |
| **空间**     | 存储空间   | 预先分配，会导致空间闲置或溢出现象                           | 动态分配，不会出现存储空间闲置或溢出现象             |
|              | 存储密度   | 不用为表示结点间的逻辑关系而增加额外的存储开销，存储密度等于 1 | 需要借助指针来体现元素间的逻辑关系，存储密度小于 1   |
| **时间**     | 存取元素   | 随机存取，按位置访问元素的时间复杂度为O(1)                   | 顺序存取，按位置访问元素时间复杂度为O(n)             |
|              | 插入、删除 | 平均移动约表中一半元素，时间复杂度为O(n)                     | 不需移动元素，确定插入、删除位置后，时间复杂度为O(1) |
| **适用情况** |            | ① 表长变化不大，且能事先确定变化的范围② 很少进行插入或删除操作，经常按元素位置序号访问数据元素 | ① 长度变化较大② 频繁进行插入或删除操作               |



### 2.7 线性表的运用

#### 线性表合并

假设有两个线性表La和Lb分别表示两个集合A和B，现要求一个新的集合A=A∪B

La=(7, 5, 3, 11), Lb=(2, 6, 3) \(\rightarrow\) La=(7, 5, 3, 11, 2, 6)

【算法步骤】

依次取出Lb中每个元素，执行以下操作：

- 1.在La中查找该元素
- 2.如果找不到，则将其插入到La的最后

```C++
void union(List &La, List Lb)
{
    La_len = ListLength(La);
    Lb_len = ListLength(Lb);
    for(int i=1; i<=Lb_len; i++)
    {
        GetElem(Lb, i, e);
        if(!LocateElem(La, e))
            ListInsert(&La, ++La_len, e);
    }
}
```



#### 有序表合并

已知线性表La和Lb中数据元素按值非递减有序排列，现要求将La和Lb归并为一个新的线性表Lc，且Lc中数据元素仍按值非递减有序排列

La=(1, 7, 8), Lb=(2, 4, 6, 8., 10, 11) \(\rightarrow\) Lc=(1, 2, 4, 6, 7, 8, 8, 10, 11)

【算法步骤】

- 创建一个空表Lc
- 依次从La或Lb中摘取元素值较小的结点插入到Lc表的最后，直至其中一个表变空为止
- 继续将La或Lb其中一个表的剩余结点插入在Lc表最后

```C++
void MergeList_Sq(SqList LA, SqList LB, SqList &LC)
{
    pa = LA.elem; // 存放首地址
    pb = LB.elem;
    LC.length = LA.length + LB.length; // 算总长度
    LC.elem = new ElemType[LC.length]; // 用指针接收申请的内存空间
    pc = LC.elem; // pc为指向LC第一个位置的工作指针
    pa_last = LA.elem + LA.length - 1; // 计算两个旧表的最后一个元素地址
    pb_last = LB.elem + LB.length - 1;
    
    while(pa<=pa_last && pb<=pb_last) // pa和pb没有越过各自最后一个元素
    {
        if(*pa<=*pb) // 具体数值比较
            *pc++=*pa++; // 将pa当前指向的值取出赋给pc当前的内存地址，赋值完分别向后移动一个元素的内存地址
        else
			*pc++=*pb++;
    }
    // pa或pb越过最后一个元素，处理没越过的另一组
    while(pa<=pa_last)
        *pc++=*pa++;
    while(pb<=pb_last)
    	*pc++=*pb++;
}
```



#### 有序表合并（链表实现）

```C++
void MergeList_L(LinkList &La, LinkList &Lb, LinkList &Lc)
{
    pa = La->next;  // pa指向La的首元结点
    pb = Lb->next;
    pc = Lc = La;   // 将La的头结点直接作为Lc的头结点，并用工作指针pc也指向它
    while(pa && pb) // 只要pa或pb遍历到底则结束循环
    {
        if(pa->data<=pb->data)
        {
            pc->next=pa;   // 将pa结点接到pc后面
            pc = pa;	   // pc指针后移，保持在当前链表尾部
            pa = pa->next; // pa指针后移，比较下一个
        }
        else
        {
            pc->next = pb;
            pc = pb;
            pb = pb->next;
        }
    }
    pc->next=pa?pa:pb; // 如果pa不为空，就将pa整串接在pc后面，否则就将pb接上
    delete Lb;		   // 释放Lb头结点
}
```

时间复杂度：O(ListLength(La) + ListLength(Lb))



### 2.8 案例分析与实现

#### 一元多项式的运算

\[
P_n(x) = p_0 + p_1x + p_2x^2 + \dots + p_nx^n
\]

线性表 \(P=(p_0, p_1, \dots, p_n)\) 每一项指数i隐含在其系数 \(p_i\) 的序号中

两个多项式相加就是其系数相加，并且次项隐藏在数组序号中



#### 稀疏多项式的运算

多项式形式： $$P(x)=\sum p_i x^{e_i}$$ 

线性表表示：$P=\boldsymbol{(p_1,e_1),(p_2,e_2),\dots,(p_m,e_m)}$，元组：**(系数，指数)**

| A(x) = $7 + 3x + 9x^8 + 5x^{17}$ |                              | B(x) = $8x + 22x^7 - 9x^8$ |                         |
| -------------------------------- | ---------------------------- | -------------------------- | ----------------------- |
| 线性表A                          | $((7,0),(3,1),(9,8),(5,17))$ | 线性表B                    | $((8,1),(22,7),(-9,8))$ |
| 系数                             | $([7,3,9,5])$                | 系数                       | $[8,22,-9]$             |
| 指数                             | $([0,1,8,17])$               | 指数                       | $([1,7,8])$             |

系数多项式运算抽象为线性表\(A = ((7,0),(3,1),(9,8),(5,17))\) 和 线性表 \(B = ((8,1),(22,7),(-9,8)) \) 的运算

【算法步骤】

- 指数相同：对应系数相加，若其和不为0，则在c中增加一个新项
- 指数不相同：则将指数较小的项复制到c中



```C++
// 使用链表
typedef struct PNode
{
    float coef;		    // 系数
    int expn;			// 指数
```

```C++
void CreatePolyn(Polynomial &p, int n)
```

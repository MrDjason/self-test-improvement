# 3. 串、数组和广义表

#### 3.1 串的定义

串：零个或多个任意字符组成的有限序列
\[
s = "a_1a_2\dots a_n"
\]

- s是串名

- \("a_1a_2\dots a_n"\)是串值

- 串长n。n=0则称空串，\(\Phi\)



子串：一个串中任意个连续字符组成的子序列（含空串）称为该串的子串

例如，"abcde"的子串有：""，"a"，"ab"， "abc"， "abcd"， "abcde"

真子串：不包含自身的所有子串

主串：包含子串的串相应地称为主串

字符位置：字符在序列中的序号为该字符在串中的位置

子串位置：子串第一个字符在主串中的位置

空格串：由一个或多个空格组成的串，与空串不同



当且仅当两个串的长度相等并且各个对应位置上的字符都相同时，这两个串才是相等的。 例： `"abcd" ≠ "abc"` `"abcd" ≠ "abcde"`

- 所有空串都是相等的



### 3.2 案例引入

串的应用非常广泛,计算机上的非数值处理的对象大部分是字符串数据,例如:文字编辑、符号处理、各种信息处理系统等等。

#### 3.3.3 串的模式匹配算法

算法目的：确定主串所含子串（模式串）第一次出现的位置

算法应用

- 搜索引擎、拼写检查、语言翻译、数据压缩

算法种类

- **BF算法**（Brute-Force，又称古典的、经典的、朴素的、穷举的）
- KMP算法（特点：速度快）



Brute-Force简称BF算法，亦称简单匹配算法

Brute-Force简称为BF算法，亦称简单匹配算法。采用穷举法的思路。

- S：主串（正文串）`a a a a b c d`
-  T：子串（模式）   `      a b c `
- 思路：从S的每一个字符开始依次与T的字符进行匹配。



**Index(S, T, pos)**

- 将主串的第pos个字符和模式串的第一个字符比较

  - 若相等，继续逐个比较后续字符

  - 若不等，从主串的下一字符起，重新与模式串的第一个字符比较
    - 直到主串一个连续子串字符序列与模式串相等。返回值为S中与T匹配的子序列第一个字符的序号，即匹配成功
    - 否则，匹配失败，返回值0



```C++
int Index_BF(SString S, SString T)
{
    int i = 1, j = 1;
    while(i <= S.length && j <= T.length){
        if(s.ch[i]==t.ch[j]){++i;++j;} // 主串和子串依次匹配下一个字符
        else{i=i-j+2;j=1;} // 主串、子串指针回溯重新开始下一次匹配
    }
    if(j>=T.length) return i-T.length; // 返回匹配的第一个字符的下标
    else return 0; // 模式匹配不成功
}
```



BF时间复杂度

例： S= '0000000001' , T= '0001' , pos=1 

若n为主串长度，m为子串长度，最坏情况是 

- 主串前面n-m个位置都部分匹配到子串的最后一位，即这n-m位各比较了m次

- 最后m位也各比较了1次 总次数为：
  \[
  (n-m)*m+m = (n-m+1)*m
  \]

若\(m \ll n\)，则算法复杂度\(\boldsymbol{O(n*m)}\)



#### KMP算法 **

利用已经部分匹配的结果而加快模式串的滑动速度

且主串S的指针i不必回溯，可提速到O(n+m)！



为此，定义`next[j]`函数，表明当模式中第j个字符与主串中相应字符“失配”时，在模式中需重新和主串中该字符进行比较的字符的位置。
\[
next[j]=
\begin{cases}
\max\{k \mid 1<k<j,\text{且 } ``p_1\dots p_{k-1}" = ``p_{j-k+1}\dots p_{j-1}"\} & \text{当此集合非空时}\\
0 & \text{当}j=1\text{时}\\
1 & \text{其他情况}
\end{cases}
\]


- \(p_1\dots p_{k-1}\)：从头开始的 \(k-1\) 个元素
- \(p_{j-k+1}\dots p_{j-1}\)：\(j\) 前面的 \(k-1\) 个元素

**next[j] 的物理含义**： 当模式串第 \(j\) 个字符失配时，说明前 \(j-1\) 个字符已经完全匹配成功。我们从这前 \(j-1\) 个字符构成的子串中，找到**最长相等的前缀和后缀**。 设最长公共前后缀的长度为 \(k-1\)（即 \(L\)），则下一轮模式串可以直接从第 \(k\) 位（即 \(L + 1\)）开始与主串的当前字符比较。



```C++
int Index_KMP(SString S, SString T, int pos)
{
    i=pos, j=1;
    while(i<S.length && j<T.length)
    {
        if(j==0 || S.ch[i]==T.ch[j]){i++;j++;}
		else
            j=next[j]; // i不变 j后退
    }
    if(j>T.length) return i-T.length; // 匹配成功
    else return 0;					  // 返回不匹配标志
}

void get_next(SString T, int &next[])
{
    i = 1; next[1] = 0; j = 0;
    while(i<T.length)
    {
        if(j==0 || T.ch[i]==T.ch[j])
        {
            ++i;++j;
            next[i] = j;
        }
        else
            j = next[j];
    }
}
```



### 3.4 数组

 **数组**：按一定格式排列起来的具有相同类型的数据元素的集合

**一维数组**：若线性表中的数据元素为非结构的简单元素，则称一维数组

**一维数组的逻辑结构**：线性结构，定长的线性表



声明格式：数据类型 变量名称[长度];

例如： int num[5] = {0, 1, 2, 3, 4};




\[
A_{m\times n}=
\begin{bmatrix}
a_{00} & a_{01} & a_{02} & \dots & a_{0,n-1}\\
a_{10} & a_{11} & a_{12} & \dots & a_{1,n-1}\\
\vdots & \vdots & \vdots & & \vdots\\
a_{m-1,0} & a_{m-1,1} & a_{m-1,2} & \dots & a_{m-1,n-1}
\end{bmatrix}
\]

\(A=(\alpha_0,\alpha_1,\dots,\alpha_p) \quad (p = m-1 \text{ or } n-1)\)

- 列向量：\(\alpha_j=(a_{0j}, a_{1j},\dots, a_{m-1,j}) \quad 0\le j\le n-1\)
- 行向量：\(\alpha_i=(a_{i0}, a_{i1}, \dots, a_{i,n-1}) \quad 0\le i\le m-1\)

二维数组：若一维数组中的数据元素又是一维数组结构，则称为二维数组。

二维数组的逻辑结构
- 非线性结构：每一个数据元素既在一个行表中，又在一个列表中。
- 线性结构（定长的线性表）：该线性表的每个数据元素也是一个定长的线性表。



声明格式：数据类型 变量名称 [行数] [列数];

例如： int num[5] [8];



在 C 语言中，一个二维数组类型也可以定义为一维数组类型（其分量类型为一维数组类型），即：
```C++
typedef elemtype array2[m][n];
```

等价于：

```c++
typedef elemtype array1[n];
typedef array1 array2[m];
```



三维数组：若二维数组中的元素又是一个一维数组，则称作三维数组。 

\(n\) 维数组：若 \(n-1\) 维数组中的元素又是一个一维数组结构，则称作 \(n\) 维数组。 

> 结论：线性表结构是数组结构的一个特例，而数组结构又是线性表结构的扩展。



数组特点：结构固定——定义后，维数和维界不再改变。

数组基本操作：除了结构的初始化和销毁之外，只有取元素和修改元素值的操作。



#### 3.4.1 数组的抽象数据类型定义

ADT Array {

**数据对象**
\[
j_i = 0,\dots,b_i-1,\quad i=1,2,\dots,n
\]
\[
D=\{a_{j_1j_2\cdots j_n}\mid a_{j_1j_2\cdots j_n}\in \text{ElemSet}\}
\]

**数据关系**
\[
\begin{aligned}
R_i=\big\{&\langle a_{j_1\cdots j_i\cdots j_n},\; a_{j_1\cdots j_i+1\cdots j_n} \rangle \;\big|\\
&0\le j_k\le b_k-1,\; 1\le k\le n,\text{且}k\neq i,\;0\le j_i\le b_i-2,\\
&a_{j_1\cdots j_i\cdots j_n},\; a_{j_1\cdots j_i+1\cdots j_n} \in D,\; i=2,\dots,n\big\}
\end{aligned}
\]

**基本操作**
1. \(\text{InitArray}(\&A,n,\text{bound}_1,\dots,\text{bound}_n)\) // 构造数组A
2. \(\text{DestroyArray}(\&A)\) // 销毁数组A
3. \(\text{Value}(A,\&e,\text{index}_1,\dots,\text{index}_n)\) // 取数组元素值
4. \(\text{Assign}(A,\&e,\text{index}_1,\dots,\text{index}_n)\) // 给数组元素赋值

} ADT Array

说明：
- \(b_i\)：第 \(i\) 维的长度
- \(j_1,j_2,\dots,j_n\)：各维度下标
- \(\text{ElemSet}\)：元素值域



#### 3.4.2 数组的顺序存储

数组特点：结构固定——维数和维界不变

数组基本操作：初始化、销毁、取元素、修改元素值，一般不做插入和删除操作

所以：一般都是采用顺序存储结构来表示数组

一维数组地址以LOC(i)=a + i*L;来表示其地址在哪
\[
二维数组有两种顺序存储方式 = \begin{cases}
以行序为主序（低下标优先）\\
以列序为主序（高下标优先） \\
\end{cases}
\]
存储单元是一维结构,而数组是个多维结构,则用一组连续存储单元存放数组的数据元素就有个次序约定问题。

**以行序为主序**

- 二维数组

设数组开始存储位置LOC(0, 0)，存储每个元素需要L个存储单元

数组元素a[i] [j]的存储位置是：LOC(i, j) = LOC(0, 0) + (n * i + j) * L

- 三维数组

a[m1] [m2] [m3]各维元素个数为 m1, m2, m3

下标为 \(i_1, i_2, i_3\) 的数组元素的存储位置：
\[
LOC(i_1, i_2, i_3) = a + i_1 * m_2 * m_3 + i_2 * m_3 + i_3
\]

#### 3.4.3 特殊矩阵的压缩存储

矩阵的压缩存储：为多个相同的非零元素只分配一个存储空间，对零元素不分配空间

- 1. 对称矩阵

存储方法：只存储下或上三角（包括主对角线）的数据元素。共占用\(\frac{n(n+1)}{2}\)个元素空间
\[
\begin{bmatrix}
a_{11} \ a_{12} \dots a_{1n} \\
a_{21} \ a_{22} \dots a_{2n} \\
\dots \ \dots \ \dots \ \dots \\
a_{n1} \ a_{n2} \dots a_{nn}
\end{bmatrix}
\]
可以以行序为主序将元素存放在一个一维数组\(sa[\frac{n(n+1)}{2}]\)

\(a_{11} \rightarrow a_{21} \rightarrow a_{22} \rightarrow a_{31} \rightarrow a_{32} \rightarrow \dots \rightarrow a_{n1} \rightarrow \dots \rightarrow a_{nn}\)

计算\(aij\)位置

- 先计算第i行之前有多少元素：\(1 + 2 + \dots + (i-1) = \frac{i(i-1)}{2}\) 个元素 
- 再计算进入第i行后有多少元素：\(a_{i1}, a_{i2}, \dots, a_{i,j-1}, a_{i, j}\)
- 所以\(a_{i, j}\)位置：\(\frac{i(i-1)}{2}+(j-1)\)



如果一维数组从下标0开始，\(k=0,1,2,\dots\)
\[
k =\frac{i(i-1)}{2}+j-1
\]

\[
k = \begin{cases} \dfrac{i(i-1)}{2} + j - 1, & i \ge j \ (\text{下三角区}) \\ \dfrac{j(j-1)}{2} + i - 1, & i < j \ (\text{上三角区，依对称性对调 } i, j) \end{cases}
\]



如果一维数组从下标0开始，\(k=1,2,3,\dots\)
$$
k =\frac{i(i-1)}{2}+j
$$

\[
k = \begin{cases} \dfrac{i(i-1)}{2} + j, & i \ge j \\ \dfrac{j(j-1)}{2} + i, & i < j \end{cases}
\]



- 三角矩阵

特点：对角线以下或以上的数据元素去哪部位常数c

存储方法：重复元素c共享一个元素存储空间，共占用\(\frac{n(n+1)}{2}+1\)个元素空间，空间sa[\(1\dots\frac{n(n+1)}{2}+1\)]

**上三角矩阵** \[ k= \begin{cases} \dfrac{(i-1)(2n-i+2)}{2}+j-i+1, & i\le j \\ \dfrac{n(n+1)}{2}+1, & i>j \end{cases} \] 

**下三角矩阵** \[ k= \begin{cases} \dfrac{i(i-1)}{2}+j, & i\ge j \\ \dfrac{n(n+1)}{2}+1, & i<j \end{cases} \]



**对角矩阵**

**特点**：\(n\times n\) 方阵，非零元素集中在以主对角线为中心的带状区域，带外全部为0；典型：三对角、五对角、七对角矩阵。

> 例：\(7\times7\) 三对角矩阵，每行最多3个非零元素，仅主对角线、上紧邻对角线、下紧邻对角线有值。

\[
\begin{bmatrix}

5 & 7 & 7 & 6 & 8 & 0 \\
0 & 9 & 6 & 9 & 1 & 5 \\

\]

| \(d\setminus j\) | 1    | 2    | 3    | 4    | 5    | 6    |
| ---------------- | ---- | ---- | ---- | ---- | ---- | ---- |

\(\delta\) 为**稀疏因子**，当 \(\boldsymbol{\delta \le 0.05}\) 时，称为稀疏矩阵。

### 3.5 广义表

广义表又称Lists，是\(n≥0\)个元素\(a_0, a_1, \dots, a_{n-1}\)的有限序列，其中每一个\(a_i\)或者是原子，或者是一个广义表



(阿根廷, 巴西, 德国, 法国, (), 西班牙, 意大利, 英国, (国家队, 山东鲁能, 广州恒大))
- 空表()：叙利亚队本该排在法国后面，但没能参赛
- (国家队, 山东鲁能, 广州恒大)：是一个子表，作为外层表的一个元素
- 广义表：拓宽了的线性表，元素可以是原子，也可以是子表



广义表通常记作：\(LS=(a_1, a_2, \dots, a_n)\)

其中，LS为表名，n为表长，每一个\(a_i\)为表的元素

- 习惯上，一般用大写字母表示广义表，小写字母表示原子



- 表头：若LS非空，则其第一个元素\(a1\)就是表头，记作\(head(LS)=a_1\)
- 表尾：除表头外的其他元素组成的表，记作\(tail(LS)=(a_2,\dots,a_n)\)

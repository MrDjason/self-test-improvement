# 基本概念

## 1.源代码结构
- 代码结构
```latex
\documentclass{article}%注释

\begin{document}

hello world

\end{document}
```

- 转义符号

```latex
\documentclass{article}
\begin{document}
50\% % \%将注释转译为%
\{\} % 用\转义其他符号
\textbackslash % 斜杠
\end{document}
```

其中`\`无法直接输入，可以通过`\textbackslash`输入斜杠

- 使用中文

```latex
%使用中文宏包
% \documentclass{ctexart} 这也支持中文
\documentclass{article}
\usepackage{ctex}
% 导言区
\begin{document}
你好
\end{document}
```

begin之前也成为导言区

## 2.标题、作者、日期

```latex
\documentclass{article}
\usepackage{ctex}

% 导言区写标题、作者、日期
\title{\Latex从入门到放弃}
\author{Kaiwen \and 张三 \and 李四} % 多个人用 \and 并列，并且可以通过\thanks{内容}添加脚注
\date{\today} % 或者 \date{2026-1-1}

\begin{document}
谢谢
\maketitle % 写在哪 标题作者日期就插入到哪

\end{document}
```

## 3.换行、分段、空格

```latex
\documentclass{article}
\usepackage{ctex}

\begin{document} % begin{document} 后面不加代码默认空两格 \noindent 可以消除空格
第一回\hspace{1em}灵根育孕源流出　心性修持大道生 \\ % 换行
% 1em空一个字的宽度 ，还可以1cm，1in（英寸）
% 用\hspace时前后空格也影响宽度

% 诗曰： \newline混沌未分天地乱 错误。\newline无大括号，后面要空一格
诗曰： \newline % 换行
\vspace{1em} % 垂直空格
混沌未分天地乱，茫茫渺渺无人见。 \\
自从盘古破鸿蒙，开辟从兹清浊辨。 \\
覆载群生仰至仁，发明万物皆成善。 \\
欲知造化会元功，须看西游释厄传。 \\
% 空段之后会缩进两个字节
  盖闻天地之数，有十二万九千六百岁为一元。将一元分为十二会，乃子、丑、寅、卯、辰、巳、午、未、申、酉、戌、亥之十二支也。每会该一万八百岁。且就一日而论：子时得阳气，而丑则鸡鸣；寅不通光，而卯则日出；辰时食后，而巳则挨排；日午天中，而未则西蹉；申时晡而日落酉；戌黄昏而人定亥。譬于大数，若到戌会之终，则天地昏蒙而万物否矣。再去五千四百岁，交亥会之初，则当黑暗，而两间人物俱无矣，故曰混沌。又五千四百岁，亥会将终，贞下起元，近子之会，而复逐渐开明。邵康节曰：“冬至子之半，天心无改移。一阳初动处，万物未生时。”到此，天始有根。 \par % 同样会分段并缩进2格

\end{document}
```

## 4.居中、取消缩进、行距

### 位置
- 居中
```latex
\begin{center}
居中 \\
\textbackslash\textbackslash 斜杠换行 \\
\textbackslash newline换行 \newline % 会发生错误居中
\end{center}
```

- 左边

```latex
\begin{flushleft}
居左（不空2格）
\end{flushleft}
```

- 右边

```latex
\begin{flushright}
居右
\end{flushright}
```

### 取消缩进

- 一行取消缩进

```latex
% 段后
\noindent
```

- 全部取消缩进

```latex
% 导言区
\parindent = 0pt
```

- 设置长度取消缩进

```latex
% 导言区
\setlength{\parindent}{0pt}
```

### 行距

`latex`基础行距是`字号×1.2`  
`word`基础行距是`字号×1.3`  
多倍行距为`基础行距×倍率`  
为了使latex的行距与word行距一样，可以定义`latex = 倍率 × 1.3/1.2`

```latex
% 导言区
\linespread{2}

% 正文区
\linespread{2}\selectfont % 修改之后所有文字行距

% 正文区
{\linespread{2}\selectfont
希望选择的文字 \par} % 分段才会生效

% 宏包
\usepackage{setspace}

% 这里都是字号的行距
\singlespacing % 单倍行距
\onehalfspacing % 1.5倍行距
\doublespacing % 2倍行距
```

## 5.字号、字体

### 字号
```latex
\documentclass{ctexart} % 中文字体 默认11磅
\documentclass[11pt]{ctexart} % 等同 11pt可以修改成10pt、11pt、12pt
```

|样本示例|命令|10pt文档|11pt文档|12pt文档|
|:---:|:---:|:---:|:---:|:---:|
|sample|`\tiny`|5pt|6pt|6pt|
|sample|`\scriptsize`|7pt|8pt|8pt|
|sample|`\footnotesize`|8pt|9pt|10pt|
|sample|`\small`|9pt|10pt|11pt|
|sample|`\normalsize`|10pt|11pt|12pt|
|sample|`\large`|12pt|12pt|14pt|
|sample|`\Large`|14pt|14pt|17pt|
|sample|`\LARGE`|17pt|17pt|20pt|
|sample|`\huge`|20pt|20pt|25pt|
|sample|`\Huge`|25pt|25pt|25pt|

- 在`document`之中，插入位置会影响该范围内（`{}`）之后行的文字
- `\fontsize{设置字体大小}{基础行距}`\selectfont  
其中`\selectfont`表示为确定生效
- 设置中文模板同样可以设置字体
```latex
\documentclass[12pt]{ctexart}` % `\usepackage{ctex}`
\zihao{字体大小}`
```

### 字体

常见字体：  

```latex
% \songti \heiti \yahei \fangsong \kaishu \lishu \youyuan
```

- `\heiti`：设置为黑体，通过\begin{}\end{}在段落内设置字体
- `{\heiti xxx}`：设置想要的内容黑体
- `\begin{heiti} \end{heiti}`：设置黑体内容


常见字体设置：  
- `\bfseries`：加粗
- `\itshape`：斜体
- `\rnfamily`：默认字体
- `\sffamily`：衬线字体（英文字符有额外装饰线）
- `ttfamily`：等宽字体

## 6.下划线、颜色

### 下划线

```latex
\usepackage [normalem]{ulem}
\uline{加下划线的内容} % 得自己手动换行 如 \\ 进行换行
\doutline{点下划线}
\sout{删除线}
\xout{更强烈的删除线}

\usepackage{CJKfntef}
\CJKunderline{加下划线的内容} % 这样字下面会有下划线并且会自动换行 标点符号下面没有
\CJKunderdblline{双下划线}
\CJKunderware{波浪线}
\CJKunderdot{点线}
\CJKsout{删除线}
\CJKxout{强烈删除线}
```

### 颜色

```latex
\color{颜色名} % 这个命令以下的字会变成别的颜色
...
{\color{red}内容} %这个花括号内部内容会变成红色
\color[rgb]{r, g, b} % 选择rgb模式 和 分量比例

%改变一段颜色和内容
\textcolor{颜色}{内容} 
\textcolor[rgb]{r, g, b}{内容}
% 设置文本背景色
\colorbox{颜色}{内容} 
\colorbox[rgb]{r, g, b}{内容}
% 设置边框颜色
\fcolorbox{边框色}{背景色}{内容}
\fcolorbox[rgb]{边框r,g,b}{背景r,g,b}{内容}
```

## 8.分页、分栏

### 分页

单栏相同

```latex
\newpage % 分页
\clearpage % 分页
```

### 分栏

```latex
\documentclass[12pt, twocolumn]{article} % 分两栏
```

分栏之后分页

```latex
\documentclass[12pt, twocolumn]{article}

\newpage % 跳到新的一栏
\clearpage % 跳到新的一页
```

## 9.摘要、摘录、脚注、边注

```latex
\documentclass[12pt]{ctexart}
\usepackage{ctex}

\begin{document}
\begin{abstract}
摘要内容
  % 需要换行
  \noindent{\textbf{关键词：}LaTex; 学习; 练习} % 摘要
\end{abstract}
% 头尾都缩进两个字符
\begin{quote} % 摘录短句
摘录内容

  \footnote{脚注}
  \marginpar{\footnotesize 边注} % 脚注大小的边注
\end{quote}

\setcounter{footnote}{100} % 设置脚注


% 头尾都缩进两个字符 本身头再缩进两个字符
\begin{quotation} % 摘录段落
摘录内容
\end{quotation}

\begin{verse} % 摘录诗歌
排版诗歌
\end{verse}

\begin{verbatim} % 代码环境
#include<iostream>
int main()
{
  ...
}
\end{verbatim}

\end{document}
```

## 10.Box

这个版面排版的时候可以划分为独立的区域（box）来进行设计和操作  

```latex
\fbox{内容} % 框出
\setlength{\fboxrule}{2pt} % 设置框线粗度
\setlength{\fboxsep}{2em} % 边框线到字符上下左右的距离

\framebox[宽度][对齐]{内容} % 对齐 —— l:left | c:center | r:right | s:分散对齐
\begin{minipage}[外对齐][高度][内对齐]{宽高} % 对齐 —— t:top | m:middle | b:bottom
\relu[升降高度]{横线宽度}{横线高度}
\rotatebox[origin=c]{角度}{内容} % \usepackage{graphicx} 翻转角度 c:center l:left r:right

% 将内容用黑框框遮住
\rlap{\rule[-2pt]{2em}{1em}} % \rlap{内容} 可以和之后的字符串重叠
```

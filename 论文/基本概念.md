# 基本概念

## 源代码结构
- 代码结构
```latex
\documentclass{article}%注释

\begin{document}

hello world

\end{document}
```

- 转义符号

```latex
\documentclass{article}
\begin{document}
50\% % \%将注释转译为%
\{\} % 用\转义其他符号
\textbackslash % 斜杠
\end{document}
```

其中`\`无法直接输入，可以通过`\textbackslash`输入斜杠

- 使用中文

```latex
%使用中文宏包
% \documentclass{ctexart} 这也支持中文
\documentclass{article}
\usepackage{ctex}
% 导言区
\begin{document}
你好
\end{document}
```

begin之前也成为导言区

## 标题、作者、日期

```latex
\documentclass{article}
\usepackage{ctex}

% 导言区写标题、作者、日期
\title{\Latex从入门到放弃}
\author{Kaiwen \and 张三 \and 李四} % 多个人用 \and 并列，并且可以通过\thanks{内容}添加脚注
\date{\today} % 或者 \date{2026-1-1}

\begin{document}
谢谢
\maketitle % 写在哪 标题作者日期就插入到哪

\end{document}
```

## 换行、分段、空格

```latex
\documentclass{article}
\usepackage{ctex}

\begin{document} % begin{document} 后面不加代码默认空两格 \noindent 可以消除空格
第一回\hspace{1em}灵根育孕源流出　心性修持大道生 \\ % 换行
% 1em空一个字的宽度 ，还可以1cm，1in（英寸）
% 用\hspace时前后空格也影响宽度

% 诗曰： \newline混沌未分天地乱 错误。\newline无大括号，后面要空一格
诗曰： \newline % 换行
\vspace{1em} % 垂直空格
混沌未分天地乱，茫茫渺渺无人见。 \\
自从盘古破鸿蒙，开辟从兹清浊辨。 \\
覆载群生仰至仁，发明万物皆成善。 \\
欲知造化会元功，须看西游释厄传。 \\
% 空段之后会缩进两个字节
  盖闻天地之数，有十二万九千六百岁为一元。将一元分为十二会，乃子、丑、寅、卯、辰、巳、午、未、申、酉、戌、亥之十二支也。每会该一万八百岁。且就一日而论：子时得阳气，而丑则鸡鸣；寅不通光，而卯则日出；辰时食后，而巳则挨排；日午天中，而未则西蹉；申时晡而日落酉；戌黄昏而人定亥。譬于大数，若到戌会之终，则天地昏蒙而万物否矣。再去五千四百岁，交亥会之初，则当黑暗，而两间人物俱无矣，故曰混沌。又五千四百岁，亥会将终，贞下起元，近子之会，而复逐渐开明。邵康节曰：“冬至子之半，天心无改移。一阳初动处，万物未生时。”到此，天始有根。 \par % 同样会分段并缩进2格

\end{document}
```

## 居中、取消缩进、行距

### 位置
- 居中
```latex
\begin{center}
居中 \\
\textbackslash\textbackslash 斜杠换行 \\
\textbackslash newline换行 \newline % 会发生错误居中
\end{center}
```

- 左边

```latex
\begin{flushleft}
居左（不空2格）
\end{flushleft}
```

- 右边

```latex
\begin{flushright}
居右
\end{flushright}
```

### 取消缩进

- 一行取消缩进

```latex
% 段后
\noindent
```

- 全部取消缩进

```latex
% 导言区
\parindent = 0pt
```

- 设置长度取消缩进

```latex
% 导言区
\setlength{\parindent}{0pt}
```

### 行距

`latex`基础行距是`字号×1.2`  
`word`基础行距是`字号×1.3`  
多倍行距为`基础行距×倍率`  
为了使latex的行距与word行距一样，可以定义`latex = 倍率 × 1.3/1.2`

```latex
% 导言区
\linespread{2}

% 正文区
\linespread{2}\selectfont % 修改之后所有文字行距

% 正文区
{\linespread{2}\selectfont
希望选择的文字 \par} % 分段才会生效

% 宏包
\usepackage{setspace}

% 这里都是字号的行距
\singlespacing % 单倍行距
\onehalfspacing % 1.5倍行距
\doublespacing % 2倍行距
```

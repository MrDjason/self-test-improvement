# 基本概念

## 1.源代码结构
- 代码结构
```latex
\documentclass{article}%注释

\begin{document}

hello world

\end{document}
```

- 转义符号

```latex
\documentclass{article}
\begin{document}
50\% % \%将注释转译为%
\{\} % 用\转义其他符号
\textbackslash % 斜杠
\end{document}
```

其中`\`无法直接输入，可以通过`\textbackslash`输入斜杠

- 使用中文

```latex
%使用中文宏包
% \documentclass{ctexart} 这也支持中文
\documentclass{article}
\usepackage{ctex}
% 导言区
\begin{document}
你好
\end{document}
```

begin之前也成为导言区

## 2.标题、作者、日期

```latex
\documentclass{article}
\usepackage{ctex}

% 导言区写标题、作者、日期
\title{\Latex从入门到放弃}
\author{Kaiwen \and 张三 \and 李四} % 多个人用 \and 并列，并且可以通过\thanks{内容}添加脚注
\date{\today} % 或者 \date{2026-1-1}

\begin{document}
谢谢
\maketitle % 写在哪 标题作者日期就插入到哪

\end{document}
```

## 4.居中、取消缩进、行距

### 位置
- 居中
```latex
\begin{center}
居中 \\
\textbackslash\textbackslash 斜杠换行 \\
\textbackslash newline换行 \newline % 会发生错误居中
\end{center}
```

- 左边

```latex
\begin{flushleft}
居左（不空2格）
\end{flushleft}
```

- 右边

```latex
\begin{flushright}
居右
\end{flushright}
```

### 取消缩进

- 一行取消缩进

```latex
% 段后
\noindent
```

- 全部取消缩进

```latex
% 导言区
\parindent = 0pt
```

- 设置长度取消缩进

```latex
% 导言区
\setlength{\parindent}{0pt}
```

### 行距

`latex`基础行距是`字号×1.2`  
`word`基础行距是`字号×1.3`  
多倍行距为`基础行距×倍率`  
为了使latex的行距与word行距一样，可以定义`latex = 倍率 × 1.3/1.2`

```latex
% 导言区
\linespread{2}

% 正文区
\linespread{2}\selectfont % 修改之后所有文字行距

% 正文区
{\linespread{2}\selectfont
希望选择的文字 \par} % 分段才会生效

% 宏包
\usepackage{setspace}

% 这里都是字号的行距
\singlespacing % 单倍行距
\onehalfspacing % 1.5倍行距
\doublespacing % 2倍行距
```

## 5.字号、字体

### 字号
```latex
\documentclass{ctexart} % 中文字体 默认11磅
\documentclass[11pt]{ctexart} % 等同 11pt可以修改成10pt、11pt、12pt
```

|样本示例|命令|10pt文档|11pt文档|12pt文档|
|:---:|:---:|:---:|:---:|:---:|
|sample|`\tiny`|5pt|6pt|6pt|
|sample|`\scriptsize`|7pt|8pt|8pt|

- 在`document`之中，插入位置会影响该范围内（`{}`）之后行的文字
- `\fontsize{设置字体大小}{基础行距}`\selectfont  
其中`\selectfont`表示为确定生效
- 设置中文模板同样可以设置字体

### 字体

常见字体：  

```latex
% \songti \heiti \yahei \fangsong \kaishu \lishu \youyuan
```

- `\heiti`：设置为黑体，通过\begin{}\end{}在段落内设置字体
- `{\heiti xxx}`：设置想要的内容黑体
- `\begin{heiti} \end{heiti}`：设置黑体内容


常见字体设置：  
- `\bfseries`：加粗
- `\itshape`：斜体
- `\rnfamily`：默认字体
- `\sffamily`：衬线字体（英文字符有额外装饰线）
- `ttfamily`：等宽字体

## 10.Box

这个版面排版的时候可以划分为独立的区域（box）来进行设计和操作  

```latex
\fbox{内容} % 框出
\setlength{\fboxrule}{2pt} % 设置框线粗度
\setlength{\fboxsep}{2em} % 边框线到字符上下左右的距离

\framebox[宽度][对齐]{内容} % 对齐 —— l:left | c:center | r:right | s:分散对齐
\begin{minipage}[外对齐][高度][内对齐]{宽高} % 对齐 —— t:top | m:middle | b:bottom
\relu[升降高度]{横线宽度}{横线高度}
\rotatebox[origin=c]{角度}{内容} % \usepackage{graphicx} 翻转角度 c:center l:left r:right

% 将内容用黑框框遮住
\rlap{\rule[-2pt]{2em}{1em}} % \rlap{内容} 可以和之后的字符串重叠
```

## 13.浮动体与图片排版

所谓浮动体，就是图片自己寻找合适的位置，不受代码文本位置控制

```latex
\begin{figure} % 浮动环境
  \centering % 居中
  \includegraphics[width=\linewidth]{img/test.jpg}
\end{figure}
```

- 控制图片位置

```latex
% h:here
% t:top
% b:bottom
% b!: 也是bottom的意思，只不过加入 ! 解除一些可能有的限制以让图片沉底
% !:解除限制
% p:page 新一页
% htbp!:让程序自己决定放在各种位置，从h到p
\begin{figure}[h] % 替换参数位置
  \centering
  \includegraphics[width=\linewidth]{img/test.jpg}
\end{figure}
```

- 图片标题`\caption`  

```latex
\begin{figure}
  \centering
  \includegraphics[width=\linewidth]{img/test.jpg}
  \caption{图片标题} % 图片标题
\end{figure}
```

- 两栏排版

`\begin{figure} → \begin{figure*}[tb]` 只能在页面底部或者顶部排版

```latex
\begin{figure*}
  \centering
  \includegraphics[width=\linewidth]{img/test.jpg}
  \caption{图片标题} 
\end{figure*}
```

- 倒品字形排版

```latex
\begin{figure}
  \centering
  \includegraphics[width=0.4\linewidth]{img/test1.jpg} \hspace{2em} % 控制上面两个图片图片间距
  % hfill 将其两边对准下面的图片，中间不管
  \includegraphics[width=0.4\linewidth]{img/test2.jpg} \\ % 换行＋垂直间距 才有用
  \vspace{1em}
  \includegraphics[width=\linewidth]{img/test3.jpg}
  \caption{图片标题} % 图片标题
\end{figure}
```

- 双图并排

```latex
\begin{figure}
  \centering
  \begin{minipage}{0.4\linewidth}
    \includegraphics[width=\linewidth]{img/test1.jpg}
    \caption{并排标题1}
  \end{minipage}
% 中间空行就会失败 不会并排而是垂直 或者 \hspace{1em} \hfill 用空格填满
  \begin{minipage}{0.4\linewidth}
    \includegraphics[width=\linewidth]{img/test2.jpg}
    \caption{并排标题2}
  \end{minipage}
\end{figure}
```

- 倒品3图带标题

```latex
\begin{figure}
  \centering
  \begin{subfigure}{0.4\linewidth}
    \includegraphics[width=\linewidth]{img/test1.jpg}
    \caption{子标题1}
  \end{subfigure} \hspace{2em}
  \begin{subfigure}{0.4\linewidth}
    \includegraphics[width=\linewidth]{img/test2.jpg}
    \caption{子标题2}
  \end{subfigure} \\ \vspace{2em}
  \begin{subfigure}{\linewidth}
    \includegraphics[width=\linewidth]{img/test3.jpg}
```

## 15.有序列表无序列表描述环境

- **无序列表**：没有编号

```latex
% 此时与markdown中的 - 列表小圆符号一致
\begin{itemize}
  \item 吃饭
  \item 睡觉
  \item 做题
\end{itemize}
% 用别的符号代替·
\begin{itemize}
  \item[*] 吃饭
  \item[+] 睡觉
  \item[~] 做题
\end{itemize}
```

- **有序列表**：有编号

```latex
\begin{enumerate} % 数字 
  \item 吃饭
    \begin{enumerate} % 字母
      \item 睡觉
        \begin{enumerate} % 罗马数字
          \item 做题
        \end{enumerate}
      \item[*] 吃饭
    \end{enumerate}
    \item[+] 睡觉
  \item[~] 做题
\end{enumerate}
```

- **解释性说明**：

```latex
\begin{description}
  \item[吃饭] 是为了更好的做题 % 吃饭加粗 可以用来进行描述说明
\end{description}
```

## 17.简单表格

- 简单格式
```latex

```

- 举例
```latex
\begin{tabular}[]{|c|l|r|c|p{4em}} % 添加边框线，c：center，l：left，r：right，p{}：限制宽度

  \hline
```

其中，[]中间填写`t、m、b`代表表格左右边字是顶部、中部、还是底部
